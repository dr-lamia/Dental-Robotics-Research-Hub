# Data and software reuse policy

Do not redistribute third-party papers, datasets, models or code without reviewing original licenses. Public accessibility does not necessarily mean permission to redistribute.

Prefer canonical DOI and project links. Record dataset size, format, annotation type, access conditions, ethics limitations, license, version and last-checked date.

Dental images and clinical CBCT data may contain identifiable patient information. Use de-identified assets with documented consent and ethical approvals where necessary. Generic simulation code does not establish medical or clinical validity.
