# Evidence classification and curation rules

This repository is a **living research index**, not a completed systematic review. A DOI link does not establish that full text, raw data, or code is open.

## Required metadata for every publication
- Full title exactly as published; first author; year; journal; DOI; publication type
- Dental specialty and robotic task
- Study setting: human clinical, cadaver, animal, phantom/printed model, in-vitro, computational/simulation, review, or unclear
- Robot autonomy: manual teleoperation, shared control, supervised autonomy, autonomous, or not reported
- Comparator and sample size (if reported)
- Primary quantitative outcomes with units and reference standard
- Data URL, code URL, license, accessibility, and last verified date
- Verification status: verified primary source, secondary-source only, or requires verification

## Evidence tiers
1. Prospective randomized clinical evidence
2. Other prospective or retrospective human clinical evidence
3. Cadaver/animal/bench experiments
4. Simulation and technical demonstrations
5. Reviews, commentaries and perspectives (index separately; do not count as original experiments)

Evidence tier is not equivalent to risk of bias or methodological quality.

## Resource availability
- Publicly downloadable: link resolves and files can be accessed
- Request access: registration, application, or author request required
- Reported but not located: paper mentions resources without a verified link
- No public release identified: search performed but no release confirmed
- Unknown: not yet assessed

## Quality control
Never infer availability from a paper's abstract. Avoid placeholder authors and abbreviated/invented titles in final citation records. Verify each DOI/title pairing at publisher or Crossref. Log search date and source. Deduplicate by DOI then title. Flag withdrawn/retracted papers. Do not copy patient datasets or third-party code into this repository without license permission.
