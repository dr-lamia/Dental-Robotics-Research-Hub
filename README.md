# Dental Robotics Research Hub

Curated, publicly accessible research index for **robotics in dentistry** — scientific papers, datasets, open-source code, digital twins, and robotic simulation.

**Status: 24 October 2026.** Seed collection, not an exhaustive PRISMA systematic review. Verify all publication and dataset metadata against original sources.

## Topics
- Robotic crown and veneer preparation (prosthodontics)
- Robotic implant placement
- Endodontic robotics
- Robotic orthodontic archwire bending
- Oral and maxillofacial surgical robotics
- Tooth extraction, motion control, force sensing
- AI-guided planning, simulation and digital twins
